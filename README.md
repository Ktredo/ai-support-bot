# AI Support Bot (RAG + Self-Correction)

Привет! Это мой пет-проект, в котором я пытался разобраться, как сделать умного AI-ассистента для службы поддержки, который не будет выдумывать факты.

**Проблема:** Обычные LLM отлично отвечают на общие вопросы, но когда их просишь найти ответ в конкретной базе знаний (PDF-инструкциях), они начинают галлюцинировать — придумывать несуществующие законы, телефоны и сроки.

**Решение:** Я собрал пайплайн, который ищет ответы в базе знаний и проверяет сам себя перед отправкой клиенту.

## ⚙️ Как это работает

1. **Triage (Анализ):** Модель читает вопрос клиента. Если клиент пишет эмоционально («ПОЧЕМУ ВЫ СПИСАЛИ ДЕНЬГИ?»), она переформулирует это в сухой поисковый запрос.
2. **Hybrid Search (Поиск):** Поиск по базе знаний идет через связку **Qdrant** (поиск по смыслу) + **BM25** (поиск по точным словам вроде "ст. 229-ФЗ"). Результаты объединяются алгоритмом RRF.
3. **Generation (Генерация):** Модель `Mistral NeMo` (через Ollama) пишет ответ, опираясь на найденные факты и правила общения (Tone of Voice).
4. **Self-Correction (Проверка):** Маленькая модель `Qwen 2.5` выступает в роли аудитора. Она ищет в ответе выдуманные факты. Если находит — заставляет основную модель переписать ответ. Если модель не справляется — выдается безопасная заглушка.

## ✨ Что реализовано

* **Разделение ответов:** Бот выдает вежливый ответ клиенту и отдельную заметку для оператора поддержки (с эмоциями и планом действий).
* **Защита от галлюцинаций:** Жесткие системные промпты + проверка второй моделью.
* **Пост-обработка:** Регулярные выражения на Python вычищают маркдаун, списки и официальные подписи, чтобы бот не писал поэмы в чат.

## 🛠 Стек технологий
* Python 3.12
* Ollama (локальный запуск LLM)
* Qdrant (векторная БД)
* SentenceTransformers, rank_bm25
* PyMuPDF (парсинг PDF)

## 🚀 Как запустить

1. `pip install -r requirements.txt`
2. Установите Ollama и скачайте модели:
   ```bash
   ollama pull mistral-nemo
   ollama pull qwen2.5:7b
3. Создайте файл .env в корне проекта (пример).
OLLAMA_URL=http://127.0.0.1:11434/api/generate
MODEL_NAME=mistral-nemo
AUDITOR_MODEL=qwen2.5:7b
4. **База знаний:** 
   Все ответы бот ищет в файле `knowledge_base.txt`. Вы можете открыть его в любом текстовом редакторе и добавить туда свои данныые.
5. Запустите: python main.py
